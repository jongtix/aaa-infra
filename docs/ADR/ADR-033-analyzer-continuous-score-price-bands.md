# ADR-033: analyzer 신호 — 연속 점수(회귀) + 이산화 계층 + 가격 밴드 스윕

- **상태**: 승인
- **일자**: 2026-07-05
- **범위**: aaa-analyzer, aaa-notifier (신호 생성·소비 계약 전체)
- **대체**: [ADR-031](ADR-031-analyzer-signal-grade-five-class.md) (5클래스 직접 출력) — 단, "STRONG = 크게 움직일 것(수익률 크기)" 의미론과 크기/확신 역할 분리는 그대로 **계승**한다

---

## 맥락

2026-07-05, "일 배치 ML 신호 + 장중 틱 등급 매칭 + 등급 변화 알림"이라는 시스템 원 구상을 업계 표준 패턴과 대조 조사했다. 조사 결론:

1. **연속 점수 + 이산화 계층이 표준**: 퀀트 실무에서 모델의 원출력은 연속 점수(기대수익률 등)이고, 5단계 등급은 그 위에 얹는 표현 계층이다. 5클래스를 직접 분류 학습하는 방식은 경계 인접 샘플의 라벨 강제 분리, 같은 구간 내 크기 차이 소실, 순서형 정보 손실, 클래스 불균형이라는 구조적 결함을 가진다.
2. **사전 계산 가격 밴드가 표준**: 장중에 변하는 모델 입력은 가격뿐이므로(나머지 피처는 전일 마감 동결), 마감 후 배치에서 모델을 가상 가격 그리드로 재평가(스윕)해 "가격 → 등급" 매핑을 사전 계산하고, 실시간 경로는 O(1) 비교만 수행하는 분리 구조가 표준이다.

당시 문서 상태는 반대 방향으로 확정되어 있었다 — PRD 8.1 "모델은 5개 등급을 직접 출력"(ADR-031), notifier 설계 [D-10] "틱 단일 구동 + 가격 수준 규칙 = 수기 %"(장중 등급 전환 개념 기각). 특히 [D-10]의 기각 심의는 "레이블 경계 산술 휴리스틱"(약한 변형)과 "회귀 모델 전환"(무거운 대안, 이연 ③)만 다뤘고, **모델 스윕 기반 밴드(중간 경로)는 심의 대상에 오르지 않았다**.

analyzer는 FOUNDATION-001만 완료(ML 파이프라인 미구현), notifier는 SPEC 미작성 상태로, 전환 비용의 대부분이 코드가 아니라 문서 개정인 시점이었다. 사용자 결정(2026-07-05)으로 표준 설계 전환을 확정했다.

---

## 결정

### 1. 모델 출력 = 연속 점수(기대수익률 회귀)

- 학습 타깃 = 예측 기간(D20/D60) **종료 시점**의 실제 수익률 그 자체(연속값, 분할+배당 조정 가격 기준 — ADR-025/[D-5] 유지)
- objective = 회귀(L2 기본, 두꺼운 꼬리 대응은 Huber/윈저라이징을 TRAIN SPEC에서 확정)
- 모델 수 8 → **16**: 포인트 8(시장2×horizon2×{LGBM,XGB}) + 분위수 보조 8(시장2×horizon2×{P10,P90}, LightGBM 전용, Optuna 비대상)

### 2. 등급 = 이산화 계층의 파생값

- 앙상블 score에 TECHSPEC 6.1 경계표(수익률 축 — 기존 표 그대로 재사용)를 적용해 5클래스 등급 파생
- 앙상블은 score 축 산술: 부호 일치 → `sign × min(|lgbm|, |xgb|)`(종전 [D-11] "낮은 강도 채택" 계승), 부호 불일치 → `0`
- 경계는 후처리 파라미터 — 변경에 재학습 불요. 남발 방지 거버넌스(문서 기록 + 반기 재검토)는 유지

### 3. confidence = 분위수 회귀 예측구간 기반 (사용자 확정 2026-07-05)

- `σ = (p90 − p10) / 2.563`, `confidence = Φ(|score_ens| / σ)` — P(방향 적중)의 정규 근사
- 종전 "방향별 확률 합"([D-12])은 클래스 확률 소멸로 대체. **크기(score)/확신(confidence) 역할 분리는 ADR-031에서 계승**
- 표준 설계의 필수 요소는 아니며(점수 단독으로도 성립), Tier 1 취지("크고 + 확실한 것만 즉시 알림") 보존과 도박성 극단 예측(기대값은 크지만 분산도 큰 패턴) 필터링을 위해 유지하기로 결정

### 4. 가격 밴드 스윕 (TECHSPEC 6.6절 신설)

- 마감 후 추론 배치에서 종목별 가상 가격 그리드(국내 ±30% 가격제한폭 / 해외 통계 범위)로 앙상블 score(p) 곡선을 산출하고, 이원 경계(승급/강등, score 마진 δ)를 가격으로 번역해 `signal_price_bands` 저장
- notifier 1단계 = 틱 가격 vs 밴드 비교로 **장중 유효 등급 판정 + 등급 전환 감지** (종전 "수기 % 가격 수준 규칙" 대체 — 원 구상의 "장중 등급 전환 알림" 복원)
- 히스테리시스는 밴드 이원 경계 + 데드존 유지 규칙으로 내장 (별도 필터 소멸)

### 5. 알림 표기 (사용자 확정 2026-07-05)

- 알림 본문 = 등급 + **score(예상 수익률 y%)** + confidence + horizon 표기

## 기각·검토 대안

| 대안 | 내용 | 기각 사유 |
|------|------|----------|
| 5클래스 직접 출력 유지 (ADR-031 설계) | 분류 모델 + 방향별 확률 합 confidence | 경계 인접 샘플 라벨 강제 분리·순서 정보 손실·클래스 불균형. 크기 축 연속 점수가 시스템 어디에도 저장되지 않아 경계 재조정=재학습, 점수 축 히스테리시스 불가, 경계 근접도 표기 불가 |
| 5클래스 유지 + 확률벡터 파생 점수 | 분류 유지, score = Σ P(클래스)×대표수익률 | 분류의 구조적 결함이 그대로 남고, 확률가중 평균은 양봉 분포에서 왜곡 — 절감폭 대비 어중간 |
| confidence 제거 (점수 단독) | 가장 단순한 순수 표준 | 성립하는 설계지만, 기대값은 크나 분산도 큰 도박성 예측이 Tier 1을 뚫는 것을 거를 축이 없음. Tier 1 취지(크고+확실) 보존을 위해 기각 (사용자 결정) |
| confidence = 두 모델 일치도 | LGBM·XGB 부호 일치+근접도 산식, 모델 8개 유지 | 산식이 임의적(ad-hoc) — "방향이 맞을 확률" 의미를 복원하지 못하고, 추후 분위수 교체 시 confidence 의미가 운영 중 변경되는 불안정성 |
| 레이블 경계 산술 휴리스틱 | 전일 종가 × 경계 %로 전환 가격 파생 | notifier [D-10] 기각 ② 유지 — 모델을 평가하지 않는 산술 승격은 근거 없음. 스윕은 모델 자체를 재평가하므로 이와 다름 |
| 밴드 없이 점수 계층만 | 회귀 전환만 하고 장중은 종전 수기 % 규칙 | 원 구상(장중 등급 전환 알림)이 미실현으로 남고, 장중 가격 판단에 ML이 관여하지 않는 반쪽 전환 |

## 명시적으로 수용한 한계

- **가상 종가 근사**: 밴드는 "장중 가격 = 가상 종가, 나머지 조건은 전일 동일" 근사다. [D-10] 기각 사유 중 "장중 목표가 불변 가정을 모델이 검증한 바 없음"은 이 설계에도 적용되며, 소멸하지 않는다. 방어는 notifier의 거래량·ATR·시간대 필터 + 확증 카운터 + 반자동(최종 판단은 사람) 구조가 담당한다
- **confidence의 가격 불변**: 신호당 1회 산출(실제 종가 기준), 가격별 재계산 없음 — 2차 효과로 판단, 운영 데이터로 필요성 입증 시 개선
- **회귀의 낮은 절대 예측력**: 금융 수익률 회귀의 R²는 구조적으로 낮다. 평가 축은 절대 정확도가 아니라 서열력(IC/Rank IC, 6.4절 지표 추가)이다

### 재검토 트리거

- 백테스트에서 score의 IC/Rank IC가 유의하게 0에 수렴(서열력 부재)하여 회귀 신호 자체의 유용성이 반증될 때
- confidence 캘리브레이션 곡선이 심하게 어긋나고 Isotonic 보정으로도 회복 불가할 때 (분위수 산출식 재설계)
- 밴드 기반 장중 등급 전환 알림이 드라이런에서 과다 발생하여 δ·병합 임계 튜닝으로 수습 불가할 때 (스윕 근사 자체의 한계 재평가)
- 가상 종가 근사로 인한 오알림이 거래량·ATR 가드로 방어되지 않음이 운영 데이터로 확인될 때
