# ADR-021: KIS 시장 코드 매핑 (fid_mrkt_cls_code → Market ENUM) 및 미지원 코드 skip 전략

- **상태**: 승인
- **일자**: 2026-04-16

---

## 맥락

KIS 관심종목 그룹별 종목조회 API 응답에는 `fid_mrkt_cls_code`, `exch_code` 두 필드가 포함된다. 이 코드표는 KIS 공식 문서에 명시되지 않은 비공개 enum 값으로, 실제 API 응답을 직접 확인하여 파악했다.

내부 Market enum(KOSPI / KOSDAQ / KRX / US / NASDAQ / NYSE / AMEX)으로 매핑하는 규칙이 필요했다.

---

## 결정

### 결정 1 — 매핑 규칙

| fid_mrkt_cls_code | exch_code | Market |
|---|---|---|
| J | KRX | KOSPI |
| UN | KRX | KOSDAQ |
| U | KRX | KRX (한국 지수) |
| N | KRX | US (미국 지수) |
| FS | NAS | NASDAQ |
| FS | NYS | NYSE |
| FS | AMS | AMEX |

매핑은 실제 API 응답 관찰 기반으로 확정했다. KIS 공식 문서에 코드표가 존재하지 않으므로 이 ADR이 유일한 매핑 근거가 된다.

### 결정 2 — 미지원 코드 처리 전략

매핑 테이블에 없는 코드 조합이 응답에 포함될 경우, **warn 로그를 남기고 해당 종목을 skip** (DB 저장 안 함)한다.

---

## 검토한 대안

### 대안 1: throw — 기각

| 항목 | 내용 |
|------|------|
| 장점 | 미지원 코드를 즉시 인지 가능 |
| 단점 | 한 종목의 코드 오류로 해당 그룹 전체 동기화 실패 |

기각. 단일 종목의 미지원 코드가 전체 동기화에 영향을 주는 것은 과도한 영향 범위다.

### 대안 2: 기본 시장 fallback (예: KOSPI로 저장) — 기각

| 항목 | 내용 |
|------|------|
| 장점 | 데이터 누락 없음 |
| 단점 | 잘못된 시장 분류가 DB에 영속됨. 이후 분석·알림에 오분류 데이터가 전파됨 |

기각. skip보다 위험하다. 잘못된 데이터를 저장하는 것이 누락보다 나쁘다.

### 대안 3: warn + skip (채택)

| 항목 | 내용 |
|------|------|
| 장점 | 잘못된 데이터 저장 없음. 누락은 다음 동기화 주기(1일 2회)에 재시도 가능. warn 로그로 감지 가능 |
| 단점 | 신규 시장 코드 추가 시 다음 동기화까지 조용히 누락됨 |

채택.

---

## 결과

미지원 `fid_mrkt_cls_code` / `exch_code` 조합이 수신되면 warn 로그를 남기고 해당 종목을 skip한다.

**리스크**: KIS가 신규 시장 코드를 추가하면 해당 종목이 조용히 누락된다. warn 로그 모니터링으로 감지 가능하다.

**재검토 트리거**: warn 로그에서 미지원 코드가 반복 감지되는 시점에 매핑 테이블을 확장하고 이 ADR을 갱신한다.
